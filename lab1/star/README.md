# Проверка настроек Nginx

Проверила конфиг и сверила его с [сохранённым прогоном](../report/evidence/check-normal.txt).

| Настройка | Что проверила | Результат |
| --- | --- | --- |
| `/docs/` | Отдельный каталог для `alias`, выключенный листинг, обычный запрос файла | `guide.txt` открывается с кодом 200 |
| `/admin` | Basic Auth для точного пути и вложенных страниц | Три запроса без пароля получили 401 и `WWW-Authenticate` |
| Виртуальные хосты | Отдельный ответ для неизвестных имён, разделение сайтов | Неизвестное имя получает 421, API первого сайта на втором возвращает 404 |

Проверка конфигурации и записанных результатов из корня репозитория

```bash
python3 lab1/star/audit.py
```

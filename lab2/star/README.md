# Docker со звёздочкой

## Запуск

Понадобятся Docker Compose от 2.24.4, cgroup v2 и Python 3. Из корня репозитория

```bash
set -o pipefail
python3 -u lab2/star/run.py 2>&1 | tee lab2-star.log
```

Скрипт поднимает отдельный Compose-проект с тестовой БД. Nginx получает свободный порт на `127.0.0.1`. При завершении скрипт удаляет созданные им контейнеры и тестовый том.

## Что проверяю

| Опыт | Условия | Что записывается в лог |
| --- | --- | --- |
| Перезапуск БД | PostgreSQL завершает работу по SIGQUIT, у контейнера настроен restart policy | ID контейнера, `RestartCount` до и после, возвращение HTTP 200 |
| CPU | 0.10 CPU, 512 МБ, 80 запросов по 8 одновременно | `docker stats`, рост `nr_throttled`, HTTP-коды, p95 |
| Память | 1 CPU, 96 МБ, 8 запросов по одному | Рост `oom_kill`, лог Gunicorn, HTTP-коды, p95 |
| Рабочие лимиты | 1 CPU и 512 МБ, те же нагрузки | Все HTTP 200, без новых OOM, прежняя заметка читается и новая записывается |

У БД выставлены 0.5 CPU и 512 МБ, у Nginx 0.5 CPU и 64 МБ. В опыте с памятью запрос выделяет 160 МиБ и обращается к страницам, чтобы ядро учло их в лимите контейнера. Итог опыта берётся из счётчика `memory.events`.
